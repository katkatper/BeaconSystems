# CJIS Security Policy v6.1 readiness mapping

Baseline: FBI CJIS Security Policy v6.1 (June 25, 2026). Owner: CJIS ISO.
This family map does not replace the official policy, state CSA requirements or a
requirement-level CJIS ISO assessment.

| Area | Beacon evidence | Remaining deployment/organization evidence |
|---|---|---|
| Governance/agreements | Phase plans, lifecycle runbook | Execute agreements/addenda; assign ISO |
| Awareness/training | Personnel policy | Approved curriculum/completion records |
| Incident response | Response/tabletop, audit/metrics | Exercise and production call tree |
| Audit/accountability | HMAC audit chain/verifier | Immutable centralized retention/alerts |
| Access control | Tenant scope, roles, MFA, sessions | Production identity and review evidence |
| Identification/authentication | MFA and session controls | Authenticator/agency validation |
| Configuration management | Manifest/drift/release gates | Deployed baselines/change approvals |
| Media/data protection | Classification/encryption policies | Media inventory/disposal evidence |
| Physical protection | Shared-responsibility review | Provider/agency evidence |
| Communications protection | TLS/CORS/encryption controls | TLS/KMS/network evidence |
| System integrity | SBOM/image scans/monitoring | Vulnerability SLA records |
| Maintenance | Release/operations procedures | Approved maintenance records |
| Personnel security | Screening/termination policy | Authorized screening records |
| Assessment/authorization | Risk/evidence templates | Independent assessment/authorization |
| Contingency planning | Recovery plan/template | Restore/failover exercises |
| Supply chain | Vendor assessment/SBOM | Signed reviews/contracts |

The CJIS ISO expands this against the official requirements and confirms current
APB and CSA direction for every deployment.
