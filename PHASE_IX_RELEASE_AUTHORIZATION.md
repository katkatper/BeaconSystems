# Phase IX controlled release authorization

Implementation status: complete. Release authorization remains external and cannot
be generated by CI or source code.

## Implementation scope

- [x] Machine-readable assurance evidence and completeness validation.
- [x] Release-blocking CI gates, SBOMs, image scanning and browser matrix.
- [x] Pilot entry/exit, rollback and national expansion criteria.
- [x] Named approval categories and explicit no-claim rule.
- [x] Post-launch monitoring, review and stop conditions.

## Authorization rule

Run `python scripts/validate_assurance_evidence.py record.json --require-complete`.
A passing structure is necessary but insufficient: reviewers inspect authentic
evidence and sign in the controlled system. No approval may be inferred from a
developer, automated test, template, sales statement or this document.
